# Figure-budget rubric

| Slot | Scientific result | Must carry | Avoid |
|---|---|---|---|
| Discovery | Matched tumor-normal / phenotype effect | N, effect size, CI/FDR | only high-expression dots |
| Mechanism | Correlated module with orthogonal control | confounder-adjusted association | module-score circularity |
| Validation | Independent cohort / assay | fixed rule, platform coverage | re-labeled internal split |
| Cell state | scRNA donor-level contrast | donors + cells, pseudobulk | cell pseudoreplication |
| Perturbation | source-supported virtual KO | null targets, stability | causal claims |
| Translation | measured drug + reversal inference | distinct evidence labels | untested drug promises |

Each slot may span 1–3 panels; larger manuscripts may expand to >6 panels/figure if legible. Figure count is a project constraint, not a scientific requirement for unrelated studies.
